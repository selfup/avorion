# Avorion Goods Filter

### [Website](https://selfup.github.io/avorion/)

Quick way to search for information about tradeable goods in Avorion!

Data comes from the Avorion wiki: https://avorion.fandom.com/wiki/Goods

### Refreshing the goods data

`goods.js` is generated by `fetchGoods.js`:

```
node fetchGoods.js
```

The script reads the current goods table from the wiki's Goods page, then walks
every station page (`Category:Stations` + `Category:Factories` plus the consumer
stations) to work out, for each good, which stations **sell** it (from their
`Production` tables) and which stations **buy** it (from their
`Production Materials` tables, mine `Goods Used` lists, and consumer-station
`Goods` lists). Fetched pages are cached in `.wiki_cache/` and reused on the
next run; delete that folder to force a full refresh.

> The old `parseWikiGoods.js` + `raw_wiki_info/` pair read the pre-2.0 Goods
> page, which carried `Sold By` / `Bought By` columns directly. The wiki dropped
> those columns in 2023, so that approach no longer works.

### Dev ENV

- VSCode with ESLint plugin
- Node 6+
- npm 5+
- Install deps: `npm install`
- Start server: `npm start`

Visit [localhost:8080](http://localhost:8080)

_page will refresh when JS or CSS is updated_

To build the JS and CSS bundles for static build: `npm run build`
